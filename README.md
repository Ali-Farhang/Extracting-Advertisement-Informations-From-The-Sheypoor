# Extracting-Advertisement-Informations-From-The-Sheypoor
Extracting ad information from the SHEYPOOR completely in every ad location and in every category

A tool for structured extraction of ads from the Sheypoor site, with full support
of all classification levels (general to detailed) and all geographical levels
(province, city, county).

## ✨ Features

- 🔍 Extract ads based on each category, from general to detailed subcategories
- 📍 Full geographical filter: province / city / county
- 🔢 Specify the desired number of ads to extract per run
- 💾 Simultaneous storage in JSON file and SQL database
- 🌐 Automatic sending of extracted data to the destination API
- 🖥️ Can be executed both via Command-Line arguments and interactive menu
- ⏱️ Request rate management (Rate Limiting) to prevent pressure on the destination server
- 🛡️ Automatic management of site entry challenges (CAPTCHA)
